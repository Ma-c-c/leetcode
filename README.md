| 思想 | 题目 | 要点 |

| 二分 · 区间定义 | 704 | 先定死闭区间还是左闭右开，所有边界操作服从它 |
| 快慢指针 | 27 | 一前一后同向，fast 探路、slow 接收 |
| 左右指针 | 977 | 相向夹逼，从后往前填结果 |
| 滑动窗口 | 209 | 不够就胀、够了就缩，边缩边记录最短 |
